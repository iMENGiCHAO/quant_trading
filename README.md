# Hyperion Pro — A股实战量化交易系统

[![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**Hyperion Pro** 是一个专注于 A 股市场的实战量化交易框架。它不仅仅是数据分析和图表展示，更核心的是为每笔交易提供**可执行的投资决策**——买什么、什么价买、买多少、什么价出、什么情况下止损。

## 设计理念

市面上大多数量化系统止步于数据可视化——画几条均线、展示K线图，然后让用户自己判断。Hyperion Pro 的不同在于：

| 传统量化工具 | Hyperion Pro |
|---|---|
| 「MACD金叉了」 | 「**买入** 600519，现价 ¥1850，目标 ¥2100，止损 ¥1750，仓位 15%，盈亏比 2.5:1」 |
| 「成交量放大」 | 「该股今日放量 3.2 倍突破 60 日新高，但大盘处于震荡市，建议**逢低建仓**，不追高」 |
| 「技术面偏多」 | 「综合评分 +58，5 个策略中 3 个看多，但基本面估值偏高，**等待回调至 ¥1720 以下再介入**」 |

## 核心功能

### 1. 数据层 — 真实行情驱动
- **实时行情**: 通过 Sina Finance API 获取沪深两市 50+ 核心标的实时报价
- **历史数据**: 日线 OHLCV，支持多周期回测
- **基本面分析**: PE/PB/ROE/股息率行业对比，估值高低一目了然
- **指数全景**: 上证/深证/创业板/科创50/沪深300 同步监控

### 2. 策略引擎 — 5 大策略并行
| 策略 | 核心逻辑 | 适用场景 |
|---|---|---|
| 趋势跟踪 | 双均线 + MACD 金叉死叉 | 单边牛市/熊市 |
| 均值回归 | 布林带 + RSI 超买超卖 | 震荡市 |
| 动量突破 | 新高突破 + 量能确认 | 强势股追涨 |
| 成交量异动 | 放量/缩量异常检测 | 主力资金监控 |
| 多因子Alpha | MA/RSI/KDJ/量价/波动率 + 基本面综合评分 | 选股决策 |

### 3. 回测引擎 — 严谨绩效评估
- 事件驱动回测，模拟真实交易流程
- 完整指标: **Sharpe Ratio**、**Sortino Ratio**、**Calmar Ratio**、最大回撤及持续期、胜率、盈亏比
- 多策略横向对比，一目了然

### 4. 投资决策引擎 — 核心差异化能力
这是 Hyperion Pro 的「大脑」，将技术分析信号转化为**可执行指令**：

```
═══════════════════════════════════════════════════════
  贵州茅台 (600519) | 食品饮料
═══════════════════════════════════════════════════════
  投资决策: 买入  |  综合评分: +58  |  置信度: 72%

  价位区间
  当前价:    ¥1850.00
  公允价:    ¥1920.00
  乐观目标:  ¥2100.00 (+13.5%)
  基准目标:  ¥1980.00 (+7.0%)
  悲观目标:  ¥1720.00 (-7.0%)

  风险控制
  硬止损:    ¥1750.00 (跌幅 5.4%)
  移动止损:  8%
  推荐仓位:  15%
  单笔风险:  2.0%
  盈亏比:    2.5:1
═══════════════════════════════════════════════════════
```

### 5. 风险管理
- VaR (Value at Risk) 计算
- 组合层面头寸控制
- 行业集中度监控
- 止损/止盈纪律执行

### 6. Web 仪表板 (Dash)
- 7 个标签页: 市场概览、个股分析、投资决策、策略信号、**策略回测**、风险监控、关于
- 交互式图表，支持鼠标悬停查看详细数据
- 一键切换标的

## 快速开始

### 环境要求
- Python 3.10+
- macOS / Linux / Windows (WSL2)
- 网络连接（用于获取实时行情）

### 安装

```bash
# 1. 克隆项目
git clone https://github.com/iMENGiCHAO/quant_trading.git
cd quant_trading

# 2. 安装依赖
pip install -r requirements.txt

# 3. 验证安装
python -c "from hyperion import get_system_info; print(get_system_info())"
```

### 命令行使用

```bash
# 完整市场分析 + 操作建议
python hyperion/cli.py

# 个股深度投资分析
python hyperion/cli.py --stock 600519

# 多只股票对比
python hyperion/cli.py --stock 600519,000858,300750

# 投资决策报告（买入信号 + 风险预警）
python hyperion/cli.py --decision

# Top N 最佳标的
python hyperion/cli.py --top 10

# 风险预警
python hyperion/cli.py --risk

# 市场状态分析
python hyperion/cli.py --market

# 策略回测
python hyperion/cli.py --backtest 600519

# 全部策略对单一股票回测
python hyperion/cli.py --backtest-all 600519
```

### Web 仪表板

```bash
python hyperion/dashboard/app.py
# 浏览器打开 http://127.0.0.1:8050
```

## 决策结果解读

### 综合评分 (Composite Score)
- **+70 以上**: 🟢 强烈买入 — 多策略一致看多，基本面/技术面共振
- **+50 ~ +70**: 🟢 买入 — 多数策略看多，风险可控
- **+30 ~ +50**: 🟡 逢低建仓 — 看多但不追高，等回调入场
- **-30 ~ +30**: ⚪ 持有/观望 — 方向不明确，不宜新开仓
- **-50 ~ -30**: 🟠 减仓 — 多数策略偏空
- **-70 ~ -50**: 🔴 卖出 — 明确看空信号
- **-70 以下**: 🔴 清仓 — 多个策略共振看空

### 盈亏比 (Reward/Risk Ratio)
- **> 2.0**: 值得交易（赚 2 块只冒 1 块的风险）
- **1.5 ~ 2.0**: 可以参与，控制仓位
- **< 1.5**: 性价比不高，建议观望

### 仓位建议
基于凯利公式优化，综合考虑胜率、盈亏比、最大回撤：
- 单票不超过总资金 20%
- 单行业不超过总资金 40%
- 总仓位根据市场状态动态调整（牛市 80%+，熊市 30%-，震荡 50-70%）

## 数据说明

- **数据源**: Sina Finance API（免费、实时、覆盖沪深两市）
- **股票池**: 50+ 只核心标的，按行业分类，覆盖食品饮料、银行、保险、证券、新能源、医药、半导体等 20+ 行业
- **更新频率**: 实时行情按需拉取，历史日线数据 T+1 更新
- ⚠️ **注意**: 数据仅供学习和研究使用，不构成投资建议。投资有风险，入市需谨慎。

## 风险声明

本系统是量化交易研究工具，所有输出（买入/卖出信号、目标价、止损位、仓位建议等）均为算法基于历史数据的统计推断，**不构成任何形式的投资建议**。实际交易请结合个人风险承受能力、资金状况和市场环境独立决策。
